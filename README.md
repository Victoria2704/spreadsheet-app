# Spreadsheet app

Итоговое задание по React и TypeScript.

Это небольшой табличный процессор. В нём можно создавать документы, открывать таблицы, менять ячейки, использовать простые формулы и сохранять данные.

## Что уже сделано

- таблица с ячейками;
- редактирование ячеек;
- простые формулы;
- создание, переименование, удаление и дублирование документов;
- импорт и экспорт CSV;
- экспорт JSON;
- Redux Toolkit;
- маршруты через React Router;
- простая авторизация.

## Как запустить

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

Проверить проект:

```bash
npm run lint
npm run test
npm run build
```
